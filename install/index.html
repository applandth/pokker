วิธีติดตั้ง Pokker บน Android

Pokker ยังไม่อยู่บน Play Store จึงติดตั้งจากไฟล์ APK บนเว็บนี้ — ทำครั้งเดียว ใช้เวลาประมาณ 1 นาที

ขั้นตอนหลัก (ทุกยี่ห้อ)

  1. กด ดาวน์โหลด APK ด้านบนด้วย Chrome บนมือถือ
  2. ถ้ามีคำเตือน "ไฟล์นี้อาจเป็นอันตราย" ให้กด ดาวน์โหลดต่อ (ไฟล์มาจากเว็บนี้โดยตรง)
  3. แตะไฟล์ pokker.apk ในแถบแจ้งเตือนหรือแอป "ไฟล์" → ติดตั้ง
  4. ถ้าระบบถามเรื่อง "ติดตั้งแอปที่ไม่รู้จัก" ให้อนุญาตสำหรับ Chrome (หรือแอปไฟล์) ตามยี่ห้อด้านล่าง แล้วกลับมากดติดตั้งอีกครั้ง
  5. ถ้า Google Play Protect ถามให้สแกน กด ติดตั้งต่อไป / ติดตั้งเลย

อัปเดตเวอร์ชันใหม่: ดาวน์โหลด APK ล่าสุดแล้วติดตั้งทับได้เลย การ์ดของฉันและการตั้งค่ายังอยู่ (แอปจะแจ้งเองเมื่อมีเวอร์ชันใหม่)

SamsungXiaomi / Redmi / POCOOPPO / realme / OnePlusvivoHuawei / HONORPixel และอื่น ๆ
Samsung (One UI)
  1. ตั้งค่า → ความปลอดภัยและความเป็นส่วนตัว → (ความปลอดภัยเพิ่มเติม) → ติดตั้งแอปที่ไม่รู้จัก
  2. เลือก Chrome หรือ ไฟล์ของฉัน → เปิด อนุญาตจากแหล่งที่มานี้
  3. ถ้าเปิด "Auto Blocker" ไว้ ให้ปิดชั่วคราวในหน้าเดียวกัน ติดตั้งเสร็จแล้วเปิดกลับได้
Xiaomi / Redmi / POCO (HyperOS / MIUI)
  1. ตั้งค่า → แอป → การอนุญาต (สิทธิ์) → ติดตั้งแอปที่ไม่รู้จัก → Chrome → อนุญาต
  2. ถ้ามีหน้าจอ "การตรวจสอบความปลอดภัย" ให้รอนับถอยหลังแล้วกด ติดตั้งต่อ
  3. บางรุ่นต้องปิด "โหมดปลอดภัย (Security mode)" ในแอปจัดการไฟล์ก่อน
OPPO / realme / OnePlus (ColorOS / realme UI / OxygenOS)
  1. ตั้งค่า → ความปลอดภัยและความเป็นส่วนตัว (หรือ "การอนุญาตแอปพิเศษ") → ติดตั้งแอปที่ไม่รู้จัก
  2. เลือก Chrome หรือ "ตัวจัดการไฟล์" → อนุญาต
  3. ถ้าระบบขอรหัสผ่านบัญชี/ล็อกหน้าจอเพื่อยืนยัน ให้ใส่ตามที่ขอ
vivo (Funtouch / OriginOS)
  1. ตั้งค่า → ความปลอดภัย (หรือ "แอปและการอนุญาต") → ติดตั้งแอปที่ไม่รู้จัก → Chrome → อนุญาต
  2. ถ้ามีหน้าจอ "ตรวจพบความเสี่ยง" ให้กด ติดตั้งต่อไป
Huawei / HONOR (EMUI / MagicOS)
  1. ตั้งค่า → ความปลอดภัย → ติดตั้งแอปจากแหล่งภายนอก → เลือกเบราว์เซอร์ที่ใช้ดาวน์โหลด → อนุญาต
  2. รุ่นที่ไม่มี Chrome ใช้ "เบราว์เซอร์" ของเครื่องดาวน์โหลดได้เหมือนกัน
Google Pixel / Motorola / Nokia / Sony / อื่น ๆ
  1. ตั้งค่า → แอป → การเข้าถึงพิเศษของแอป → ติดตั้งแอปที่ไม่รู้จัก → Chrome → อนุญาต
  2. หรือแตะไฟล์ APK แล้วกด "การตั้งค่า" จากหน้าต่างที่เด้งขึ้นมา ระบบจะพาไปหน้าเปิดสิทธิ์ให้เอง
